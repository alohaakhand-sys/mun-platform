## 🐛 New Bugs / Issues Discovered in Audit

1. **Duplicate ProGate components** — `src/components/ProGate.tsx` (uses hook) AND `src/components/features/organizer/ProGate.tsx` (reads profile directly). Different prop names (`feature` vs `featureName`, `lockedFallback` vs `fallback`). Risk of inconsistency. **Recommendation:** consolidate to the canonical `/components/ProGate.tsx` version and update all imports.

2. **ProGate not yet wrapping all Pro features** — Only 3 of 5 planned features gated:
   - ✅ Live MUN module (in `conferences/[id]`)
   - ✅ Bulk Email >50 recipients (in `AnnouncementComposer`)
   - ✅ Custom Theme Colors (in `tools/theme`)
   - ❌ AI Country Assignment button — not wrapped
   - ❌ Ornate certificate template — not wrapped

3. **ApplicationWizard Faculty/Team validation** — `submitFacultyApplication` and `submitTeamApplication` exist in `applicationService` but need verification that the server-side Team child-applications creation is complete (parent + N children linked by `teamApplicationParentId`).

4. **CertificateDownload wired but Cloud Function missing** — Client calls `httpsCallable(functions, 'generateCertificate')` but `functions/src/generateCertificate.tsx` does not exist yet. This will throw a "function not found" error if a delegate tries to click "Download PDF". **Recommendation:** either create the Cloud Function (Phase B) or add a feature flag to disable the button until the function is deployed.

5. **waitlistService lacks offer lifecycle** — `offerSeat()` sets status + notifiedAt, but `acceptOffer()` and `expireOffer()` don't exist yet. The organizer can offer seats, but delegates can't accept and the 48h expiry doesn't fire.
