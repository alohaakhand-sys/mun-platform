Scan passes

One page for the counter: pick what you're handing out (a meal, coupon, check-in day or ride; "Now" items sort first), start the camera, scan. Each scan returns one of nine result cards. Green is Claimed, with Undo. Amber covers already used, outside meal time (with "Accept anyway") and paused. Red covers not for them, not a MUN Pilot pass, another event, reset pass and Pro required. "Check only" mode looks a pass up without redeeming it. Organizer-level users can redeem by name. "Claimed so far" counts on demand. Decision: the page now sits inside the event sidebar (Tools › Scan Passes); the phone layout is what staff use at the counter.
