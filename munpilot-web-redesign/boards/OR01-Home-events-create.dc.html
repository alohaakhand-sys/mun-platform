Organizer home, Manage Events, Create event

Organizer home keeps the four totals, Events at a Glance, Applications by Role and Your Events. Manage Events keeps the chips, All / Published / Drafts, search and event cards (Draft / Published, Co-organizer, format, committees, delegates). Create event keeps every field in order — cover, host, name, date and time with time zone and optional end, format, venue search with a draggable map pin (or meeting link), visibility and an AI-assisted description — and notes that it saves as a draft.
