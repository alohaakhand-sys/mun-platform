CP03 · Conference portal · optional modules

Food, Transport, Accommodation, Dress Code

Each module shows only when the organizer turns it on. Food coupons become ticket stubs grouped by day, with the QR on a tear-off edge. Transport puts your registration first as a boarding pass, then the routes with seats-left bars. Accommodation is one tap per room block, then a status card. Dress Code leads with the reference photo and the requirement. Every module keeps its empty state.
