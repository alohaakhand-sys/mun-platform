Admin overview, users and events

The admin shell keeps its red "System Admin" card and the twelve-item sidebar. Overview shows four totals, recent activity and what needs attention. Users is a paged table with role changes; each member has a detail page (verified badge, plan overrides, AI use, disable / delete, their events and payouts). Events lists every conference with a row menu — publish or draft, Plan & limits, Test allocation, Delete — and the plan dialog sets an event's tier, caps, features and fee.
