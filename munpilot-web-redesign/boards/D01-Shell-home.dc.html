Dashboard shell and home

The shell every dashboard page sits in: 256px sidebar (Menu + role sections, collapsible to 76px), user card with the bell at the bottom, the floating Messages bubble, and on phones a top bar with a slide-in drawer. Active nav is a soft green fill instead of a solid slab. Home keeps hero → three stat cards → Recent activity beside Recommended and the organiser promo. Overlays — notifications, profile menu, messages panel — are drawn underneath.
