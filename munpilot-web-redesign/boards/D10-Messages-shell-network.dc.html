Messages, shell and network states

Messages gets the New Message dialog, the floating panel's new-chat view, group bubbles with sender names, the delivery ticks, presence and every empty line, plus the phone chat screen with a back arrow. The shell gets the notification bell's states (role-change invite, room alert pills, error strip), the live-session pop-ups (bottom-right, 5s), the new rail items (My Pass, Scan Passes, Coupons, Pass Report, Faculty Panel), the co-organizer and App Admin menus, and the organizer home variants. Network and profile add their empty states, confirm dialogs and "Profile not found".
